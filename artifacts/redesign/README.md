# Native UI previews

Rendered Flutter screens using **fictional test fixtures** (Preview Café,
preview@example.com, sample step/point totals and SR-DEMO-PASS). These are not
live partner offers, customer records or evidence of reward partnerships.

The previews use the production widgets, router, theme, fonts and icons at
414 dp. Generate them with the command in `UI_REDESIGN.md`. Device acceptance
and API deployment evidence are recorded separately in `LAUNCH_AUDIT.md`.
